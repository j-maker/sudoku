# Release 1.0.4 (versionCode 5)

## Artefactos

| Archivo | Ruta |
|---------|------|
| AAB | `store-assets/release/1.0.4/sudoku-1.0.4-v5.aab` |
| Símbolos nativos | `store-assets/release/1.0.4/native-debug-symbols.zip` |
| Notas de versión | `store-assets/release-notes-1.0.4.txt` |

## Play Console

1. **Prueba interna** o **Producción** → Crear versión
2. Subir `sudoku-1.0.4-v5.aab`
3. Subir `native-debug-symbols.zip` (Desofuscación / símbolos nativos)
4. Pegar novedades desde `release-notes-1.0.4.txt`
5. Revisar y publicar

## Cambios principales

- Menú ⋮ unificado (stats, clasificaciones, instrucciones, ajustes, sonido)
- Play Games: leaderboards y logros
- Layout `SpaceBetween` en pantallas altas
- Sonido apagado por defecto
- Mejoras analytics y estabilidad de anuncios fullscreen
